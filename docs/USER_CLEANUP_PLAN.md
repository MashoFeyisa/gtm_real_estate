Generated by `php artisan users:cleanup --dry-run` on 2026-10-14 16:14:48.

**Status: APPROVED (`approved`) and EXECUTED.** Verification results are in the execution log at the bottom of this file.

**Goal:** exactly one user account per role. The main administrator is never removed, and the last account of a role is never removed.

## Rules applied (one consistent rule)

| Record type | Handling |
| --- | --- |
| Financial records, ledger entries, payments, commissions, invoices, audit logs, activity logs | Never deleted, never reassigned. The owning user is anonymized in place and soft-deleted, so references stay valid. |
| Per-user permission grants (`user_roles`, `user_permissions`, `user_permission_overrides`) | Deleted with the removed user — the kept account carries its own grants. |
| Sessions, API tokens, password reset tokens | Deleted with the removed user. |
| One-to-one profiles (`agents`, `company_white_labels`) | The kept account keeps its row; the removed user's fields are merged into it when empty, then the extra row is deleted. |
| Every other record referencing the removed user (properties, listings, bookings, offers, leases, documents, messages, reviews, viewings, inquiries...) | Reassigned to the kept account of the same role. |

A removed user without financial/audit rows is hard-deleted after reassignment; an owner of financial/audit rows is soft-deleted (`deleted_at`) and anonymized to `Removed User #id`.

Merge mechanics (one transaction, integrity-checked):

1. `UPDATE users SET role = :target WHERE role = :source`.
2. `user_roles` pivot rows repointed from the source `role_id` to the target `role_id` (duplicates skipped).
3. `role_permissions`: every permission key the source has that the target lacks is inserted for the target, so **no capability is lost**; the source rows are then deleted.
4. The source `roles` catalog row is deleted (its permission rows were migrated above).
5. Direct grants (`user_permissions`, `user_permission_overrides`) are keyed by `permission_id`, not role, so they are untouched.
